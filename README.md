## About

I build software that turns complex data and repetitive workflows into reliable products.

My work sits at the intersection of data, automation and product engineering: visual desktop automation, real-time event processing, operational monitoring, data validation, controlled SQL workflows, SaaS integrations and WhatsApp-based experiences.

Across my projects, I work end to end — from Python services, APIs, browser automation and computer vision to React/TypeScript interfaces, PostgreSQL-backed systems and automated testing.
